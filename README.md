# AI Vision Today

Personal guide by Oleh Rudko about using AI as a tool: mindset, context, verification, practice, and moving toward real results.

## Website

- Site: https://oleh-rudko.github.io/ai-vision/
- Ukrainian version: https://oleh-rudko.github.io/ai-vision/ai-ua.html
- English version: https://oleh-rudko.github.io/ai-vision/ai-en.html
- Russian version: https://oleh-rudko.github.io/ai-vision/ai-ru.html

## Files

- `index.html` — language selector for GitHub Pages.
- `ai-ua.html` — Ukrainian animated guide.
- `ai-en.html` — English animated guide.
- `ai-ru.html` — Russian animated guide.
- `au-en.html` — redirect kept so the old English URL does not break.
- `og-uk.png`, `og-en.png`, `og-ru.png` — 1200×630 link preview images.

All guides are single self-contained files: fonts, styles, and scripts are inlined, so they work offline and need no build step.
